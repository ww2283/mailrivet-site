mailrivet Privacy Policy

Last updated: November 24, 2026

What mailrivet is

mailrivet is a command-line program that runs only on the owner's own computer. It is a personal tool used by its owner with the owner's own accounts. It has no server, no website backend, and no accounts of its own.

Google user data it accesses

With the owner's consent, mailrivet requests these Google permissions:

  • gmail.readonly: to search and read the owner's messages and threads.
  • gmail.compose: to create draft messages in the owner's Drafts folder. mailrivet does not send, delete, or move mail.

How the data is used and stored

Message content is read on the owner's computer only to answer the owner's own commands. mailrivet does not transmit Gmail data to any server operated by its author or by anyone else. Sign-in credentials are stored in the operating system's secure keyring on the owner's computer. A local log records actions taken, not message content.

Sharing

mailrivet does not sell, share, or transfer Google user data to third parties. The owner may choose to pass command output to a local AI assistant on their own computer; that is the owner's decision, outside mailrivet.

Google API Services User Data Policy

mailrivet's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

The owner can revoke mailrivet's access at any time at myaccount.google.com/permissions and delete the stored credentials from the local keyring.

Contact

Questions about this policy: open an issue at https://github.com/ww2283/mailrivet-site/issues.
