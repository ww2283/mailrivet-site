mailrivet

mailrivet is a command-line tool that runs on the owner's own computer. It lets the owner search and read their own Gmail and Outlook.com mail and create unsent draft messages. It never sends, deletes, or moves mail.

It is a personal tool for a single user. It is not offered to the public and has no servers or user accounts.

See the Privacy Policy.

Questions: open an issue at https://github.com/ww2283/mailrivet-site/issues.
